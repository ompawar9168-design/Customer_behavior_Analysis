📊 Data Analytics Project
📌 Overview
This project demonstrates an end-to-end Data Analytics workflow, starting from raw data handling to generating actionable insights. It includes data loading, cleaning, exploratory data analysis (EDA), SQL-based querying, dashboard creation in Power BI, and final reporting using PPT (Gamma).
The goal is to analyze data efficiently and present insights in a clear and business-friendly manner.

Type: CSV

Python (Pandas, NumPy, Matplotlib, Seaborn)
SQL (MySQL )
Power BI (Dashboard & Visualization)
Jupyter Notebook

**🔄 Project Workflow / Steps**

1. Data Loading
Imported dataset using Python (Pandas)
Checked structure using .head(), .info(), .describe()
2. Data Cleaning
Handled missing values
Removed duplicates
Fixed data types
Renamed columns for consistency
4. Exploratory Data Analysis (EDA)
Analyzed trends and patterns
Performed statistical analysis
Visualized data using charts (bar, pie, histogram, boxplot)
5. SQL Analysis
Imported cleaned dataset into SQL database
Performed queries such as:
Filtering data
GROUP BY aggregations
Joins (if multiple tables)
Business insights extraction
6. Power BI Dashboard
Created interactive dashboard
Added KPIs (Key Performance Indicators)
Used filters and slicers
Built visual reports for decision-making
